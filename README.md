# NR BizPro

**One Platform. Every Business.**

NR BizPro is a simple multi-business billing SaaS concept focused on bill generation and bill history. The customer's own payment collection is outside NR BizPro.

## Current MVP
- Business settings
- Products / services list
- Cost price + percentage/fixed margin
- Automatic selling price calculation
- Bill generation
- Bill history and search
- Print invoice
- Responsive desktop/mobile UI
- Browser local storage demo data

## Next production modules
1. Signup/login
2. Subscription plans and payment activation
3. Secure multi-tenant database
4. Production authentication and roles
5. Subscription expiry/renewal
6. PDF invoice generation and WhatsApp sharing
7. Super Admin panel

The current UI is a front-end MVP; production payments, authentication and server-side persistence still need to be connected before commercial launch.
